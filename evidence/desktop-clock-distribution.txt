## Reason for the experiment and its boundary

The user reports clean VGA before the timing-placement changes, then stable
sync with terrible vertical black lines afterward, while the Dell E772c
continues to report about 44.9 kHz / 59.9 Hz. Flat white, eight-pixel red/green,
constant grey and two-pixel grey controls were clean; clear-only changes did
not improve the desktop. See the preceding VGA evidence files. The user
approved directly investigating the timing/clock-distribution regression
instead of more colour-pattern controls.

Review of this nextpnr fork found that pack_buffered_nets skips PLL drivers
without a CLOCK attribute. Direct dedicated PLL routing also filters its
first hop to a spine or another PLL output, while the installed chipdb gives
this PLL output a local F0 first hop. Forcing CLOCK alone inserts a BUFG,
but the ordinary clock router still falls back across the DCS bridge.
That CLOCK-only candidate had a hold violation and was never packed or loaded.

tools/desktop-clock-distribution.py splits pll_nes.PLL_inst/CLKOUT0 from the
existing clk net, adds desktop_main_pll with CLOCK=1, and adds a virtual DCS
desktop_main_distribution in static DCS_MODE=CLK0. CLKIN0 is the raw PLL net;
CLKOUT retains the original clk bit and all original consumers. Other inputs,
CLKSEL and SELFORCE are unconnected because this is a static selection.
The vendor's local GW5A simulation library describes CLK0 as a pass-through;
that is a logical primitive description, not proof of these packed fuses.

The helper reproduces the exact tested PNR input. Reversing just the new cell,
new net and PLL-output split yields exact equality with the baseline input.
No renderer functions, PLL recipes, raster frequencies, or existing data
connections were changed. Full placement/routing was rerun; existing physical
data routes and placement are therefore not held constant in this experiment.
No FPGA source RTL or external repository was modified. Colibri-SV conventions
were consulted at 9715bdd701b148966d339b2749c29c24eca9a651 as a reference only;
no third-party module or vendor source was copied into this change.
